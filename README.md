## 🌲 نبذة عن المشروع (Project Overview)

**الغابة الأسيرة (The Captive Forest)** هي لعبة مغامرات ثلاثية الأبعاد تعتمد كلياً على اللعب التعاوني بين لاعبين اثنين (Two-Player Co-op) متصلين عبر شبكة محلية (**LAN**).

تستند فلسفة اللعبة إلى مفهوم **التكافل الحقيقي (Interdependence)**؛ حيث يستيقظ اللاعبان في غابة أسطورية سلبت منها عناصر الحياة الأساسية (الضوء، الماء، والرياح) لتقبع في ظلام وسكون تام. يمتلك كل لاعب قلادة سحرية متصلة بقلادة شريكه، تتيح لهما **التواصل الصوتي المباشر** وتتوهج كلما اقتربا من بعضهما. لا يمكن للاعب واحد اجتياز العقبات بمفرده؛ بل يتطلب التقدم تبادل المعلومات، توجيه الرؤية، جمع الموارد، والتنسيق الزمني الدقيق لحل الألغاز وإعادة الحياة إلى الغابة.

## 🌟 الركائز الأساسية للعبة (Core Pillars)

1. **التعاون القائم على التواصل (Communication-Driven Co-op):**
   - التواصل الصوتي المباشر عبر الشبكة المحلية (LAN Voice Chat) هو شريان اللعبة الأساسي.
   - تبادل المعلومات الوصفية وتنسيق الأدوار هو مفتاح حل الألغاز المعقدة.

2. **القلادة السحرية ومؤشر القرب (Proximity & Resonance):**
   - جوهرتا القلادتين مترابطتان كوانتياً/سحرياً؛ تتوهجان وتتغير مؤثراتهما البصرية والصوتية مع اقتراب اللاعبين، مما يسهل اللقاء والتنقل.

3. **التحول البيئي الديناميكي (Dynamic World Restoration):**
   - تحرير كل عنصر طبيعي (ضوء، ماء، ريح) يحدث تحولاً دراماتيكياً فورياً وملموساً في البيئة:
     - **الضوء:** كشف المسارات المظلمة، تنشيط الإضاءة الحجمية (Volumetric Lighting).
     - **الماء:** تفجر الشلالات وتدفق النهر الجاف، نمو النباتات على الضفاف.
     - **الرياح:** تحرك الأشجار، انتشار أوراق الشجر والمؤثرات الجوية، واستعادة الأصوات البيئية.

4. **تحديات متنوعة بدون تعقيد (Accessible & Engaging):**
   - آليات واضحة وغير معقدة: استكشاف، توجيه مرايا، إصلاح سد وتفعيل متسلسل زمني، وتفعيل متزامن لنقاط تحكم شجرة الرياح، مع نظام جمع موارد مباشر وخفيف.

## 🛠️ المواصفات التقنية المقترحة (Technical Stack)

| المكون | التقنية المختارة | التفاصيل والتبرير |
|---|---|---|
| **محرك التطوير** | Unity 2022.3 LTS أو Unity 6 | استقرار طويل الأمد وأحدث ميزات التظليل والشبكات |
| **خط الرندرة** | Universal Render Pipeline (URP) | مرونة عالية في الإضاءة والشيدرات والمؤثرات البصرية |
| **بنية الشبكة** | Netcode for GameObjects (NGO) + UTP | حل يونتي الرسمي المستقر لنمط Host-Client مع دعم الشبكة المحلية |
| **اكتشاف الشبكة** | UDP Broadcast LAN Discovery | العثور التلقائي على جهاز الـ Host بدون كتابة IP يدوياً |
| **التواصل الصوتي** | LAN VoIP / Dissonance or Custom Stream | نقل صوتي منخفض الكمون عبر UDP محلياً وبدون إنترنت |
| **نظام الإدخال** | Unity New Input System | دعم كامل للوحات المفاتيح وأيدي التحكم بمرونة |
| **الشيدرات والمؤثرات** | Shader Graph & VFX Graph | توهج القلادة، تحول ألوان الغابة، وانبعاث الجزيئات |
