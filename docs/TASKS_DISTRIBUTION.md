## 🎯 خطة التسليم المتدرج (Sprint Milestones)

```
[الأسبوع 1: التأسيس] ──► ربط LAN ناجح + حركة اللاعبين + مجسمات أولية بسيطة (Blockout) + شيدر القلادة
[الأسبوع 2: الألغاز] ──► لغز كبسولة الضوء + لغز السد والمؤقت + استبدال المجسمات بنماذج بلندر النهائية
[الأسبوع 3: الشجرة والبيئة] ──► لغز الشجرة المتزامن + شيدرات الماء والرياح والذوبان + المؤثرات البصرية
[الأسبوع 4: الصقل والتسليم] ──► تكامل الصوتيات + البوابة السينمائية الختامية + اختبار LAN المتكامل الشامل
```
